# Font fixture

`Ahem.ttf` is the deterministic test font from
[web-platform-tests](https://github.com/web-platform-tests/wpt/blob/master/fonts/Ahem.ttf),
downloaded on October 11, 2026. Tests serve it locally and do not require a font
service or network access.
