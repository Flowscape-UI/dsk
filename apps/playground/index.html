AnglePreview

A compass-style control with a soft sector, a direction needle, and a clear center value. Choose degrees, radians, multiples of π, turns, or gradians.

Angle preview

Live

Try an angle

Zero is at the top. Values increase clockwise; the soft sector starts at the minimum angle. The scale and center value follow the selected unit. Rotation is continuous until you set a minimum or maximum.

Angle properties

EDIT LIVE

Continuous rotation. Leave both bounds empty to keep rotating through a full turn, or set either bound to stop at endpoints.

Values, bounds, and step use degrees. Changing the unit converts them while keeping the same physical angle.

Angle HTML

CUSTOM ELEMENT

CurvePreview

Curve preview

Live

Click the line to add · Drag points to adjust
Delete to remove a node · Escape to cancel

Selected preset ease-in-out Change events 0

Time runs left to right; progress runs bottom to top. Points stay within 0–1 and nodes keep their time order. Start and end points are movable too. Play preview animates the dot without changing the selected curve.

Curve properties

EDIT LIVE

Accepts a preset name, four coordinates, a CSS cubic-bezier() value, or a saved curve(...) value with additional nodes.

The graph always stays square. Coordinate fields support precise edits of the selected point; all handles can be reached with Tab.
