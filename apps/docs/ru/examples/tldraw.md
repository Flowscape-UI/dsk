DSK можно добавить в готовый редактор, сохранив его движок. В этом примере tldraw отвечает за объекты, выделение, трансформации, камеру и историю. DSK добавляет две линейки, метку-комментарий и панель изменения позиции и поворота.

<ClientOnly><TldrawExample /></ClientOnly>

Пример запускается автоматически. Переместите или поверните прямоугольник средствами tldraw, затем измените X, Y или Поворот через инпуты DSK. Выберите эллипс, чтобы редактировать другой объект. Колесо/трекпад перемещают камеру, кнопка **Уместить** возвращает объекты в поле зрения. Потяните от линейки для создания направляющей; Delete удаляет линию в фокусе. Комментарий остаётся привязан к прямоугольнику независимо от выделения.

SDK загружается при открытии страницы. Пока редактор не готов, виден индикатор загрузки. Изменения хранятся в памяти и сбрасываются при уходе со страницы. Комментарий - аннотация DSK, а не ветка обсуждения tldraw. Направляющие помогают визуально, но не добавляют привязку объектов к линиям в движке tldraw.

::: info Лицензия tldraw
Пример использует tldraw 5.5.2 и React 18.3.1. У tldraw собственная лицензия, отдельная от MIT-лицензии DSK. Локальная разработка доступна без ключа. Для публикации нужен действующий ключ tldraw для вашего хоста: задайте `VITE_TLDRAW_LICENSE_KEY` перед сборкой. Сохраняйте атрибуцию SDK. Подробнее в [официальных условиях и инструкции по ключам](https://tldraw.dev/community/license).
:::

## 1. Установите зависимости

В приложении Vite с TypeScript:

```sh
npm i @flowscape-ui/dsk tldraw@5.5.2 react@18.3.1 react-dom@18.3.1
npm i -D @types/react@18 @types/react-dom@18
```

React нужен tldraw, а не DSK. В примере используется `createElement`, поэтому все файлы остаются обычными TypeScript-файлами. В существующем React-приложении можно вывести `<Tldraw />` и передать editor из onMount в тот же адаптер DSK.

```text
index.html
src/
  main.ts
  mount-example.ts
  bind-dsk.ts
  style.css
```

## 2. Подготовьте область редактора

Viewport имеет заданную высоту. Строка и колонка по 24px отводятся линейкам. Начала шкал совпадают с внутренней областью редактора, а не со страницей или панелью инпутов над ней.

```html
<!-- index.html -->
<div id="example"></div>
<script type="module" src="/src/main.ts"></script>
```

Функция монтирования ниже создаёт три независимые области:

- Инпуты DSK за пределами поверхности событий tldraw.
- React root с настоящим компонентом Tldraw.
- Overlay без трансформации камеры, содержащий dsk-canvas-marker.

Overlay не перехватывает жесты холста. Линейки получают viewport через свойство `.target`; глобальный CSS-селектор не нужен.

## 4. Преобразуйте координаты камеры

tldraw и DSK по-разному представляют pan:

```ts
// tldraw: viewportPoint = (pagePoint + cameraPosition) * zoom
// DSK:    viewportPoint = worldPoint * zoom + pan
const { x, y, z } = editor.getCamera();
const camera = { panX: x * z, panY: y * z, zoom: z };
xRuler.camera = camera;
yRuler.camera = camera;
comment.camera = camera;
```

Например, камера tldraw `{ x: 40, y: -20, z: 2 }` преобразуется в DSK `{ panX: 80, panY: -40, zoom: 2 }`. Мировая точка (100,50) окажется в точке (280,60) CSS-пикселей внутри viewport.

Не добавляйте сюда прокрутку документа и положение viewport на странице. Линейки и метка уже отсчитывают координаты от его начала. Не применяйте повторный CSS-transform камеры к overlay. Для другого движка выведите соответствующее преобразование из его API. Смотрите [системы координат](https://tldraw.dev/sdk-features/coordinates) и [камеру tldraw](https://tldraw.dev/sdk-features/camera).

## 5. Свяжите выделение, инпуты и комментарий

Сохраните код в `src/bind-dsk.ts`. Функция react здесь - реактивная подписка tldraw, а не React hook. Она отслеживает камеру, выделение и изменения объектов и возвращает функцию очистки.

<<< @/snippets/tldraw/bind-dsk.ts

Связь работает в обе стороны:

1. tldraw изменяет объект или выделение. Подписка обновляет поля DSK, линейки и метку.
2. Событие input от DSK изменяет выбранный объект tldraw. Программное присваивание значения DSK не отправляет input, поэтому цикл событий не возникает.
3. Поворот переводит градусы в радианы и использует rotateShapesBy, чтобы сохранить поведение вращения вокруг центра. При этом X/Y также могут измениться.
4. В начале правки поля создаётся точка истории. Undo отменяет правку целиком, а не каждый промежуточный шаг перетаскивания.

Значение активного поля не перезаписывается во время ввода. Инпуты расположены вне редактора, а editor.blur() не позволяет горячим клавишам холста перехватывать их ввод.

### Границы примера

Панель редактирует один незаблокированный объект, родителем которого является текущая страница. При пустом или множественном выделении, а также для вложенного объекта поля отключаются. X/Y вложенного объекта заданы относительно его родителя. Для поддержки таких объектов нужно осознанное преобразование между координатами страницы и родителя. Подробнее: [трансформации объектов tldraw](https://tldraw.dev/sdk-features/shape-transforms).

### Привязка комментария

Аннотация хранит стабильный ID прямоугольника. getShapePageBounds возвращает ограничивающую рамку в координатах страницы; метка следует за её правым нижним углом при перемещении, изменении размера и повороте. Удаление прямоугольника скрывает комментарий, Undo возвращает его. Смена выделения не переносит комментарий на другой объект. В продукте храните ID и текст в модели документа и выберите, привязывается ли метка к рамке или к локальной точке фигуры.

## 7. Запуск и очистка

```ts
// src/main.ts
import { mountExample } from './mount-example.ts';

const root = document.querySelector<HTMLElement>('#example');
if (!root) throw new Error('Missing example root');
const dispose = mountExample(root);

// On route unmount: dispose();
if (import.meta.hot) import.meta.hot.dispose(dispose);
```

Очистка останавливает реактивную подписку, удаляет слушатели DSK и размонтирует React. Отключение линеек также удаляет их overlay с направляющими. Для SSR загружайте модуль только на клиенте, когда контейнер уже существует; инициализировать tldraw и DSK на сервере не нужно.

Для публичного размещения создайте `.env.local` с публичным лицензионным ключом tldraw и пересоберите проект:

```dotenv
VITE_TLDRAW_LICENSE_KEY=your-public-tldraw-license-key
```

Здесь нет специального пакета-обёртки, форка tldraw или отдельного движка DSK. В своём редакторе можно повторить ту же схему: преобразовать камеру, прочитать выделение и изменять модель через публичный API.

## 8. Изучите и скачайте проект

Ниже можно просмотреть всю структуру проекта. У каждого файла есть исходный код и короткое объяснение. Файлы редактора взяты из живого примера, поэтому скачиваемый проект соответствует этому руководству.

Скачайте и распакуйте ZIP, откройте терминал в папке `dsk-tldraw-example` и выполните `npm install`, затем `npm run dev`. Нужны Node.js 22.12+ и интернет для установки зависимостей. Архив содержит собранную копию DSK в папке `vendor`; npm установит её автоматически. Настраивать [монорепозиторий](https://github.com/Flowscape-UI/dsk) не нужно. Команда `npm run build` проверит типы и соберёт приложение. Для публичного размещения по-прежнему нужен ключ tldraw, описанный выше.
