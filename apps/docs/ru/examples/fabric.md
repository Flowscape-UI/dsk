Используйте интерактивный холст Fabric как движок, а DSK как внешнюю панель параметров. Fabric управляет выделением, перетаскиванием, масштабом и поворотом объектов. Те же инпуты, линейки и комментарий DSK, что и в остальных примерах, подключаются к публичному API Fabric.

<ClientOnly><EngineExample engine="fabric" /></ClientOnly>

Редактор загружается вместе со страницей. Перетаскивайте прямоугольник или эллипс, меняйте размер и угол маркерами либо редактируйте X, Y и поворот через DSK. Нажатие на пустое место снимает выделение, его перетаскивание перемещает камеру. Перед масштабированием колёсиком нажмите на холст. Escape освобождает фокус для обычной прокрутки страницы. **Уместить** показывает обе фигуры, **Сбросить** возвращает исходные трансформации.

Комментарий следует за прямоугольником, даже если выбран другой объект. Вытягивайте направляющие из линеек и удаляйте их клавишей Delete, когда на них установлен фокус. Это отдельные элементы DSK, они не становятся объектами Fabric и не добавляют привязку. Изменения хранятся в памяти до ухода со страницы.

Общая панель держит нативные контролы за пределами области жестов Fabric. Линейки привязаны к внутреннему viewport, а комментарий получает мировые координаты и ту же камеру, что и холст.

`setSelection` обновляет инпуты и отключает их при пустом выделении. `onTransform` принимает изменения пользователя. Программное присваивание значения DSK не генерирует `input` и не создаёт циклические обновления. Панель также не перезаписывает значение активного инпута во время редактирования.

## 3. Подключите Fabric и создайте объекты

Сохраните код в `src/fabric/mount-example.ts`. Именно этот адаптер работает в интерактивном примере.

`Canvas` добавляет собственный слой взаимодействия поверх HTML canvas. У обоих объектов явно задано центральное начало координат, поэтому X/Y в панели обозначают центр. Выделение ограничено одной из двух фигур, а перетаскивание пустого места перемещает камеру вместо создания рамки множественного выделения.

Видимые маркеры трансформации предоставляет Fabric. DSK не рисует их имитацию и не заменяет взаимодействие движка.

## 4. Прочитайте выделение и примените изменения DSK

Свойства `left`/`top` относятся к заданному началу координат объекта. `angle` измеряется в градусах. При центральном начале координат адаптер использует эти значения напрямую:

```ts
shell.onTransform((field, value) => {
  const object = selected();
  if (!object) return;
  if (field === 'rotation') object.rotate(value);
  else object.set(field === 'x' ? 'left' : 'top', value);

  // External changes must refresh controls and hit-testing coordinates.
  object.setCoords();
  canvas.requestRenderAll();
  sync();
});
```

Вызов `setCoords()` важен: простое изменение свойств объекта не обновляет кеш координат для проверки попадания и маркеров выделения. После каждого рендеринга адаптер читает активный объект, поэтому жесты на холсте тоже обновляют DSK. См. [API геометрии объекта](https://fabricjs.com/api/classes/fabricobject/).

Панель намеренно обрабатывает только прямоугольник и эллипс. Для групп или множественного выделения сначала определите, к каким координатам относятся X/Y: к родителю группы или ко всей сцене.

## 5. Преобразуйте матрицу камеры

Fabric хранит камеру в аффинной матрице из шести значений. В этом примере используются только равномерный масштаб и смещение, поэтому дополнительное преобразование для DSK не нужно:

```ts
// Fabric matrix: [zoom, 0, 0, zoom, panX, panY].
// DSK: screen = world * zoom + pan.
const matrix = canvas.viewportTransform;
shell.setCamera({
  panX: matrix[4],
  panY: matrix[5],
  zoom: canvas.getZoom(),
});

// getBoundingRect() returns scene coordinates, before the camera transform.
const bounds = rectangle.getBoundingRect();
shell.setMarker(bounds.left + bounds.width, bounds.top + bounds.height);
```

Не применяйте камеру к точке привязки заранее: `dsk-canvas-marker` делает это самостоятельно. Положение контейнера на странице не является смещением камеры. Поворот или скос камеры потребовал бы другой интеграции линеек; здесь оси камеры совпадают с осями холста.

Для масштабирования относительно курсора `canvas.zoomToPoint()` принимает точку в пикселях viewport и новый масштаб. Перемещение меняет смещение матрицы через `setViewportTransform()`. Обе операции обновляют линейки и комментарий. См. [API Canvas](https://fabricjs.com/api/classes/canvas/).

## 6. Добавьте стили и очистку

Общие стили совмещают линейки с холстом, задают высоту viewport и оформляют панель DSK в тёмной теме:

<<< @/snippets/shared/example-shell.css

```ts
// src/main.ts
import { mountExample } from './fabric/mount-example.ts';

const root = document.querySelector<HTMLElement>('#example');
if (!root) throw new Error('Missing example root');
const dispose = mountExample(root);

// Also call dispose() when the owning route or component unmounts.
if (import.meta.hot) import.meta.hot.dispose(dispose);
```

Очистка отключает наблюдатель за размерами и DOM-обработчики, удаляет подписки Fabric и вызывает `canvas.dispose()`. Fabric завершает запланированную отрисовку перед освобождением ресурсов. Проверка флага `disposed` не даёт этой последней отрисовке обновить уже удалённую панель DSK.

Для SSR импортируйте модуль в клиентском обработчике жизненного цикла после появления контейнера. Холст, DOM-контролы и наблюдатель за размерами работают в браузере.

## 7. Изучите и скачайте проект

Ниже находится полный рабочий проект с комментариями и общей панелью. В ZIP вы получите те же исходники и собранный пакет DSK в папке `vendor`.

Нужны Node.js 22.12+ и интернет для установки зависимостей. Распакуйте ZIP, откройте терминал в `dsk-fabric-example`, выполните `npm install`, затем `npm run dev`. Команда `npm run build` проверяет типы и собирает приложение.
