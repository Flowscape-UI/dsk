# Konva.js + DSK

Небольшой редактор на основе сцены Konva и нативных компонентов DSK. Konva рисует объекты, управляет их выделением и трансформациями. DSK добавляет инпуты позиции и поворота, линейки, направляющие и комментарий, привязанный к прямоугольнику.

<ClientOnly><EngineExample engine="konva" /></ClientOnly>

Редактор загружается вместе со страницей. Перетащите фигуру, измените её размер или угол маркерами, затем отредактируйте X, Y или поворот в панели. Нажатие на пустое место снимает выделение, а перетаскивание пустого места перемещает камеру. Перед масштабированием колёсиком нажмите на холст. Escape освобождает фокус, чтобы снова можно было прокручивать страницу. **Уместить** показывает обе фигуры, **Сбросить** возвращает исходные трансформации. Выберите эллипс, чтобы изменить другой объект теми же инпутами.

Вытяните направляющую из любой линейки. Чтобы удалить её, установите на неё фокус и нажмите Delete. Направляющие DSK здесь служат визуальными ориентирами и не добавляют привязку в Konva. Комментарий остаётся у прямоугольника при смене выделения. Изменения хранятся в памяти и сбрасываются при уходе со страницы.

## 1. Установите зависимости и создайте контейнер

Пример использует Konva 10.7.1 в приложении Vite с TypeScript. Фреймворк и дополнительная обёртка над Konva не нужны.

```sh
npm i @flowscape-ui/dsk konva@10.7.1
```

```html
<!-- index.html -->
<div id="example"></div>
<script type="module" src="/src/main.ts"></script>
```

Переиспользуемая панель DSK отделена от движка:

```text

  konva/

  shared/
    example-shell.ts
    example-shell.css
```

## 2. Создайте панель DSK

`createExampleShell` создаёт три `dsk-input`, две линейки и отдельный слой с `dsk-canvas-marker`. Движок получает только `surface`. Целью линеек служит `viewport`, поэтому их начало координат совпадает с холстом, а не со всей страницей.

<<< @/snippets/shared/example-shell.ts

Панель принимает выделенный объект, камеру и точку привязки комментария. Обратные вызовы сообщают об изменении инпутов и действиях кнопок. Программное присваивание значения DSK не вызывает `input`, поэтому синхронизация не зацикливается. Значение активного инпута не перезаписывается во время редактирования.

## 3. Подключите настоящий холст Konva

Это полный адаптер работающего примера выше. Сохраните его как `src/konva/mount-example.ts`.

<<< @/snippets/konva/mount-example.ts

`Stage` отвечает за камеру, `Layer` содержит фигуры, а `Transformer` предоставляет маркеры выделения. Нажатие на фигуру подключает её к трансформеру. При пустом выделении инпуты DSK отключены. Панель намеренно редактирует один объект за раз.

При изменении размера Konva меняет `scaleX` и `scaleY`, а не ширину и высоту прямоугольника. Поэтому **Сбросить** возвращает исходный масштаб вместе с позицией и углом. Подробнее в официальном [примере Transformer](https://konvajs.org/docs/select_and_transform/Basic_demo.html).

## 4. Свяжите позицию и поворот

Смещение прямоугольника равно половине его ширины и высоты, поэтому X/Y обозначают центр. У эллипса начало координат уже находится в центре. И жесты движка, и инпуты DSK поворачивают фигуру вокруг центра. Konva измеряет угол в градусах, как и наша панель.

```ts
shell.onTransform((field, value) => {
  if (!selected) return;
  if (field === 'rotation') selected.rotation(value);
  else if (field === 'x') selected.x(value);
  else selected.y(value);
  sync();
});
```

Адаптер слушает `dragmove` и `transform`, чтобы отражать изменения на холсте в инпутах. Он читает текущие значения движка и не создаёт вторую модель объектов.

## 5. Передайте камеру линейкам и комментарию

Позиция и масштаб сцены Konva напрямую соответствуют камере DSK:

```ts
// Both use: screen = world * zoom + pan.
shell.setCamera({
  panX: stage.x(),
  panY: stage.y(),
  zoom: stage.scaleX(),
});

// Exclude the stage transform to get an anchor in world coordinates.
const bounds = rectangle.getClientRect({ relativeTo: stage });
shell.setMarker(bounds.x + bounds.width, bounds.y + bounds.height);
```

В примере масштаб одинаков по обеим осям, камера не поворачивается. Комментарий следует за правым нижним углом ограничивающего прямоугольника после изменения размера или поворота фигуры. Это аннотация DSK, а не объект документа Konva. В настоящем редакторе сохраняйте её текст и идентификатор связанной фигуры в модели документа.

Обработчик колёсика сначала находит мировую точку под курсором, меняет масштаб, затем корректирует позицию сцены, чтобы эта точка осталась на месте. См. [пример масштабирования относительно курсора](https://konvajs.org/docs/sandbox/Zooming_Relative_To_Pointer.html). Прокрутка документа не входит в координаты камеры.

## 6. Добавьте стили и запустите пример

Общие стили задают высоту холста, совмещают начало координат линеек и создают слой комментария, который не перехватывает жесты холста:

<<< @/snippets/shared/example-shell.css

```ts
// src/main.ts
import { mountExample } from './konva/mount-example.ts';

const root = document.querySelector<HTMLElement>('#example');
if (!root) throw new Error('Missing example root');
const dispose = mountExample(root);

// Also call dispose() when your route or component unmounts.
if (import.meta.hot) import.meta.hot.dispose(dispose);
```

Функция очистки отключает наблюдатель за размерами, удаляет DOM-обработчики, уничтожает сцену Konva и удаляет панель DSK. Для SSR импортируйте модуль динамически на клиенте после появления контейнера. Браузерный холст Konva и пользовательские элементы DSK не нужно монтировать при серверном рендеринге.

## 7. Изучите и скачайте проект

Просмотрите все файлы ниже или скачайте ZIP. Адаптер движка и общая панель взяты из тех же исходников, которые работают на этой странице. Архив содержит собранный пакет DSK в `vendor`, поэтому пример запускается независимо от этого [репозитория](https://github.com/Flowscape-UI/dsk).

Нужны Node.js 22.12+ и интернет для установки зависимостей. Распакуйте архив, откройте терминал в `dsk-konva-example`, выполните `npm install`, затем `npm run dev`. Команда `npm run build` проверяет типы и создаёт сборку для публикации.
